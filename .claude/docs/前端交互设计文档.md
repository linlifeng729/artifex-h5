# Artifex-H5 前端交互设计文档

> 定义 Artifex NFT 数字藏品交易 H5 应用的视觉设计规范、交互模式、组件规范。

## 1. 视觉设计规范

### 1.1 设计风格

**风格名称**：Dark Glassmorphism（深色玻璃态）

整体采用深色沉浸式设计语言，以半透明玻璃叠加和柔和光晕营造现代感与科技感，强调内容主体同时保留视觉呼吸空间。

### 1.2 色彩系统

#### 主色
| 色值 | 用途 |
|------|------|
| `#3cb371` | 主按钮、选中状态、重要强调（极客绿） |

#### 背景渐变
| 用途 | 色值 |
|------|------|
| 首页背景渐变 | `linear-gradient(135deg, #1a1a2e, #16213e, #0f3460)` |
| 登录页背景 | `#000000` |

#### 玻璃态遮罩
| 用途 | 色值 |
|------|------|
| 卡片/面板背景 | `rgba(255, 255, 255, 0.1)` |
| 输入框背景 | `rgba(255, 255, 255, 0.05)` |
| 聚焦输入框 | `rgba(255, 255, 255, 0.1)` |
| 毛玻璃效果 | `backdrop-filter: blur(10px)` |
| 边框 | `1px solid rgba(255, 255, 255, 0.3)` |

#### 文字色
| 用途 | 色值 |
|------|------|
| 主文字 | `#ffffff` |
| 次级文字 | `rgba(255, 255, 255, 0.6)` |
| 占位符文字 | `rgba(255, 255, 255, 0.4)` |

#### 功能色
| 用途 | 色值 |
|------|------|
| 错误/警告 | `linear-gradient(135deg, #ff4757, #ff3742)` |
| 成功 | `linear-gradient(135deg, #4ecdc4, #26de81)` |
| 主题标题渐变 | `linear-gradient(to right, #60a5fa, #a855f7, #f472b6)` |

#### Tab 选中态
| 用途 | 色值 |
|------|------|
| 选中背景 | `rgba(255, 255, 255, 0.25)` |
| 未选中文字 | `rgba(255, 255, 255, 0.6)` |
| 选中文字 | `#ffffff` + `font-weight: 500` |

#### 底部导航激活态
| 用途 | 色值 |
|------|------|
| 激活图标颜色 | `#FFD700` |
| 激活光晕 | `0 0 10px rgba(255, 215, 0, 0.5)` |

### 1.3 圆角规范

| 组件 | 圆角值 |
|------|--------|
| 按钮 | `8px` |
| 输入框 | `8px`（聚焦时边框变为 `#3cb371`） |
| 卡片/面板 | `16px` |
| 大面板 | `24px` |
| 胶囊 Tab | `40px`（足够大使其看起来像胶囊） |

### 1.4 阴影规范

| 用途 | 值 |
|------|------|
| 毛玻璃面板 | `box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15)` |
| 聚焦输入框 | `box-shadow: 0 2px 16px rgba(60, 179, 113, 0.2)` |
| 主按钮 | `box-shadow: 0 4px 16px rgba(60, 179, 113, 0.4)` |
| 特殊功能按钮 | `box-shadow: 0 4px 16px rgba(102, 126, 234, 0.4)` |

### 1.5 间距规范

| 用途 | 值 |
|------|------|
| 页面边距 | `16px`（`mx-4`） |
| 组件间距 | `12px` 或 `16px` |
| 卡片内边距 | `12px ~ 16px` |
| 底部安全区 | `padding-bottom: 90px`（BottomNav 高度） |
| 顶部安全区 | `padding-top: 75px`（TopHeader 高度） |

### 1.6 字体规范

使用系统字体栈，无需引入外部字体：
```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
```

| 用途 | 大小 |
|------|------|
| 页面标题 | `28px ~ 32px`，`font-weight: 700` |
| 卡片标题 | `14px ~ 15px`，`font-weight: 500 ~ 600` |
| 正文 | `14px` |
| 辅助文字 | `12px` |
| 按钮文字 | `14px ~ 16px` |

## 3. 组件规范

### 3.1 搜索栏

```html
<!-- 玻璃态搜索栏 -->
<div class="mx-4 my-3"
  style="background: rgba(255, 255, 255, 0.1);
         border: 1px solid rgba(255, 255, 255, 0.3);
         border-radius: 24px;
         padding: 12px 16px;
         backdrop-filter: blur(10px);">
  <input placeholder="🔍 搜索藏品名称" />
</div>
```

### 3.2 Tab Selector

两种风格：

**胶囊风格（TopHeader）**：
```html
<div class="rounded-full"
  style="background: rgba(255, 255, 255, 0.15);
         padding: 4px;
         border: 1px solid rgba(255, 255, 255, 0.3);">
  <!-- 选中项 -->
  <div class="rounded-2xl"
    style="background: rgba(255, 255, 255, 0.25);
           box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15);">
  </div>
</div>
```

**文字横排风格（MarketOverview / MyAssets）**：
```html
<div class="flex items-center justify-center gap-6 p-3 mx-4 my-3 rounded-2xl
  backdrop-blur-sm border border-white/30 bg-white/10">
  <!-- 选中项 -->
  <div class="text-white font-medium">推荐</div>
  <!-- 未选中项 -->
  <div class="text-white/60">在售</div>
</div>
```

### 3.3 列表卡片

```html
<div class="bg-white/10 border border-white/30 rounded-2xl mx-4 my-3 p-0">
  <!-- 列表项 -->
  <div class="flex items-center justify-between h-[75px] px-3 py-3
             border-b border-white/30"
       :class="{ 'border-b-0': isLastItem }">
    <!-- 左侧：图标 + 文字 -->
    <div class="flex items-center gap-2">
      <div class="w-10 h-10 rounded-full border border-white/30"
           style="backgroundImage: url(...)"></div>
      <div class="text-sm text-white font-medium">{{ name }}</div>
      <div class="text-xs text-white/60">{{ count }}</div>
    </div>
    <!-- 右侧：价格 -->
    <div class="text-sm text-white font-medium">¥{{ price }}</div>
  </div>
</div>
```

### 3.4 状态组件

**LoadingState**：居中显示，加载时可见。
**EmptyState**：居中显示，数据为空且未加载时可见。

### 3.5 底部导航

```html

  style="background: rgba(255, 255, 255, 0.1);
         height: 90px;
         border-top: 1px solid rgba(255, 255, 255, 0.3);
         backdrop-filter: blur(10px);">
  <!-- 5 个导航项 -->
  <div class="nav-item-active">
    <span>🏠</span>
    <span>首页</span>
  </div>

```

### 3.6 登录页特殊设计

- 背景：`#000000`
- 3D 浮动方块装饰（CSS animation `float`）
- 标题渐变色：`background-clip: text`
- 聚焦输入框：边框变 `#3cb371` + 绿色阴影

## 4. 交互动效规范

### 4.1 基础动效

| 动效名称 | CSS | 用途 |
|----------|-----|------|
| 悬浮缩放 | `transform: scale(0.98)` | 卡片/按钮按下 |
| 悬浮缩放（反向） | `transform: scale(0.96)` | 分类卡片 |
| 列表淡入 | `opacity: 0 → 1, translateY: 20px → 0` | 分类卡片入场 |

### 4.2 加载动画

```css
/* 旋转加载 */
@keyframes spin {
  to { transform: rotate(360deg); }
}
.loading-spinner {
  border: 2px solid rgba(255, 255, 255, 0.1);
  border-top-color: rgba(255, 255, 255, 0.6);
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
```

### 4.3 浮动动画（登录页）

```css
@keyframes float {
  0%, 100% { transform: translateY(0px) rotateX(45deg) rotateY(25deg); }
  50% { transform: translateY(-10px) rotateX(65deg) rotateY(45deg); }
}
.animate-float {
  animation: float 6s ease-in-out infinite;
}
.animation-delay-1000 { animation-delay: -1s; }
/* ... 其他 delay */
```

### 4.4 过渡时长

| 动效类型 | 时长 |
|----------|------|
| 颜色/透明度过渡 | `0.2s ~ 0.3s` |
| 缩放/位移过渡 | `0.25s ~ 0.3s` |
| 旋转加载 | `0.8s ~ 1s linear infinite` |
| 浮动动画 | `6s ease-in-out infinite` |
| 延迟 stagger | `0.05s` 递增 |

## 5. 响应式设计

### 5.1 断点
本项目为 H5 应用，主流屏幕宽度 375px ~ 428px。以移动端优先设计，无需桌面端响应式。

### 5.2 安全区适配
使用 CSS 变量或硬编码值适配 iOS 底部安全区：
```css
padding-bottom: calc(90px + env(safe-area-inset-bottom));
```

## 6. 性能注意事项

- 图片使用 `background-image` + `background-size: cover` 而非 `<img>`（减少布局抖动）
- 避免在模板中使用复杂计算表达式
- 搜索防抖：`lodash-es` 的 `debounce`，500ms 延迟
- 列表懒加载：数据量增大时考虑虚拟滚动

## 7. 无障碍（Accessibility）

- 输入框必须有 `placeholder` 提示
- 交互元素（按钮、Tab）需要有适当的点击区域（高度 ≥ 44px）
- 颜色对比度需满足 WCAG AA 标准（文字与背景的对比度 ≥ 4.5:1）
- focus 状态通过边框/阴影指示，不依赖纯色变化
